# Datos generados con Deepseek distill

Este CSV incluye los siguientes campos relevantes para una aplicación de Uber:

RideID: Identificador único de cada viaje.
DriverID: Identificador del driver que realizó el viaje.
PassengerID: Identificador del pasajero que ocupó el viaje.
PickupLocation y DropoffLocation: Ubicación de inicio y fin del viaje.
pickupTime y dropoffTime: Horario de inicio y fin del viaje.
FareAmount: Monto total del viaje.
PaymentMethod: Método de pago utilizado.
TripPurpose: Motivo por el cual se realizaron los viajes.
Puedes personalizar estos ejemplos según tus necesidades específicas para la aplicación de Uber.

-- Eliminar tabla si existe con el mismo nombre
DROP TABLE IF EXISTS uber_rides;

-- Crear la tabla
CREATE TABLE uber_rides (
    RideID STRING,
    DriverID STRING,
    PassengerID STRING,
    PickupLocation STRING,
    DropoffLocation STRING,
    pickupTime TIMESTAMP,
    dropoffTime TIMESTAMP,
    FareAmount DECIMAL(6,2),
    PaymentMethod STRING,
    TripPurpose STRING
);

-- Ordenamos por duración de viaje
SELECT
    RideID,
    DriverID,
    PassengerID,
    PickupLocation,
    DropoffLocation,
    pickupTime,
    dropoffTime,
    FareAmount,
    PaymentMethod,
    TripPurpose,
    (unix_timestamp(dropoffTime) - unix_timestamp(pickupTime)) / 60 AS DurationMinutes
FROM
    uber_rides
ORDER BY
    DurationMinutes DESC;
